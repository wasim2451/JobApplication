# 🧑‍💼 Job Application Portal

A Node.js-based web application that allows users to submit job applications and enables the admin to view submitted data in a modern dashboard.

## 🚀 Features

- 📄 Application form with fields for name, email, phone, DOB, address, position, experience, and resume link.
- ✅ Form validation with proper input types.
- 🗃 Data stored in MySQL database.
- 🔐 Admin panel to view all submissions.
- 💅 Clean UI using Tailwind CSS.
- ⚙️ Backend built with Express.js and mysql2.

---

## 📦 Tech Stack

- **Frontend**: HTML, EJS, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MySQL (via mysql2)
